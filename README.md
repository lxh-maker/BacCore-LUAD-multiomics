# BacCore-LUAD multiomics analysis

This repository contains the deidentified figure-level source data and R code accompanying:

> **Multiomic characterization of a Baciptosis core machinery-associated mitochondrial stress state in lung adenocarcinoma**  
> Xiaohan Liu and Dong Zhang

## Study scope

The analysis prespecifies an equal-weight **BacCore** score based on six genes/proteins: **BAX, BAK1, VDAC1, VDAC2, PHB, and PHB2**. For each dataset, the score is the mean of gene-wise standardized abundance values.

The repository reproduces the six main figures from deidentified, derived source tables. It does not redistribute patient-level raw data from TCGA, GEO, or CPTAC. The results describe the abundance and biological context of Baciptosis core machinery; they do **not** demonstrate Baciptosis activation, multiprotein complex assembly, mitochondrial DNA efflux, or cell-death execution.

## Reproduce the figures

R 4.3 or later is recommended. Install the required packages once:

```r
install.packages(c("data.table", "ggplot2", "patchwork", "scales"))
```

From the repository root, run:

```bash
Rscript scripts/reproduce_main_figures.R
```

The script writes publication-resolution PNG and vector PDF files to `figures/`:

1. Study design and interpretive boundary
2. Differential expression and WGCNA context
3. Pathway associations and apoptosome-interaction boundary
4. Sample-level single-cell localization
5. CPTAC protein-level validation
6. Four-cohort survival meta-analysis

## Data provenance

- **TCGA-LUAD:** bulk RNA sequencing and clinical annotations obtained through the Genomic Data Commons/TCGA resources.
- **GSE131907:** single-cell RNA sequencing data obtained from NCBI GEO.
- **GSE68465, GSE31210, and GSE72094:** public lung adenocarcinoma expression and survival cohorts obtained from NCBI GEO.
- **CPTAC-LUAD:** transcriptomic and proteomic data obtained from the CPTAC data resources.

Users should obtain the original datasets from their respective repositories and comply with the original access conditions and citation requirements. The tables in `source_data/` are derived statistics used solely to reproduce the displayed figures. Direct sample identifiers were removed; paired CPTAC observations use arbitrary sequential pair labels.
