# Figure source data

These tab-separated tables are deidentified, derived analysis outputs used by `scripts/reproduce_main_figures.R`.

| File | Main content |
|---|---|
| `Figure_2A_BacCore_DE.tsv` | Differential-expression estimates for the six BacCore genes |
| `Figure_2B_module_trait.tsv` | Selected WGCNA module-trait correlations |
| `Figure_2C_hub_DEG_overlap.tsv` | Robust differentially expressed WGCNA hub genes |
| `Figure_3A_TCGA_pathways.tsv` | Adjusted pathway associations in TCGA-LUAD |
| `Figure_3B_TCGA_independent_mtDNA.tsv` | BacCore and independent mtDNA-stress scores without sample identifiers |
| `Figure_3C_apoptosome_interactions.tsv` | Prespecified apoptosome interaction models |
| `Figure_4_single_cell_pseudobulk.tsv` | Sample-level epithelial pseudobulk scores without original sample identifiers |
| `Figure_4B_single_cell_correlations.tsv` | Sample-level pathway correlations |
| `Figure_5A_CPTAC_paired_scores.tsv` | Paired CPTAC protein scores with arbitrary sequential pair labels |
| `Figure_5B_CPTAC_RNA_protein_scores.tsv` | CPTAC RNA-protein score pairs without sample identifiers |
| `Figure_5C_CPTAC_pathways.tsv` | CPTAC protein-pathway correlations |
| `Figure_6_survival_cohorts.tsv` | Cohort-specific survival estimates |
| `Figure_6_meta_analysis.tsv` | Random-effects meta-analysis estimate |

These files are not substitutes for the original TCGA, GEO, or CPTAC datasets.
